## v1.8 更新

- 应用名称改为“快了记账”。Android 11 及以上可在启用本应用无障碍服务后，使用专用快捷设置入口截图记账；Android 8–10 保留原有记账功能。普通截图不作为记账指令。
- 数字在设备上离线识别，可在对应位置选择一个候选并修正金额，再选择收入或消费以及必选备注；点击“记录”后才保存。原图仅用于临时处理，不长期保存。受系统保护的画面可能无法截取。
- 消费选择早餐、午餐、晚餐或其他内置备注时，金额累加到操作当天对应项；自建备注消费与全部收入保存为独立流水，显示在用户页。收入与消费的自建备注分别保存和复用。
- 用户页分别统计消费与收入，各币种分开计算。新增流水使用账户默认币种；当天已有非零消费项的币种与默认币种冲突时，应用提示冲突并拒绝累加。
- 备份格式包含新增独立流水和自建备注，并支持读取旧版备份。

## 原有功能

- 单日首页显示早餐、午餐、晚餐和其他消费，支持七天日期栏、月历和过去日期记录；用户页支持月度统计、图表和颜色设置。
- 支持默认和加减两种记账模式、快捷或谨慎确认方案，以及日期批量选择与删除。
- 按账户设置时区、三餐时间和默认币种。人民币、美元、英镑分别统计，不进行汇率换算；金额以非负 Long 整数最小货币单位保存，最多两位小数。
- 本地多账户隔离、中文 / English / 日本語和加密备份恢复；无云同步。

## 截图记账

在“用户 → 截图记账设置”查看启用方式，将“截图记账”添加到系统快捷设置。打开需要记账的画面后，使用专用快捷开关，点选数字，修正后选择收支及备注，最后点击“记录”。取消或未确认时不会记账。

截图和识别功能包含在应用中，不需要另装截图或 OCR 插件。截图能力依赖 Android 11 及以上和系统无障碍授权；部分应用或受保护画面可能无法截图。
