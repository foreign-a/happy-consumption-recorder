# v1.6 验收摘要

## 功能与修复

- 数字键盘移除透明容器的8dp阴影，使用当前主题的平面背景，修复顶部及两侧黑边；减模式同步显示红色。
- 快捷模式：修改午餐等任意一项金额后，点击其余三项之一，先保存本次输入，再编辑所点金额。单击当前金额不保存；点击编辑区外仍可保存。保存失败或输入无效时，保留原草稿和编辑位置。
- 谨慎模式：键盘右上角新增“确认保存”，直接保存当前草稿；切换金额仍可连续编辑多项，点击编辑区外仍提供“确认保存／放弃更改／继续编辑”。升级保留既有确认方案；未设置过的账户默认谨慎。
- 所有记账与确认方案均支持删除键按住2秒后每80毫秒逐位删除，松手、移出按键或手势取消即停止；短按仍只删除一位。重复删除不直接修改已保存数据。

## 验证

74项JVM单元测试、31项Android设备回归测试通过；调试和正式构建通过，Lint为0错误、17项警告。

- 新增9项JVM测试，覆盖午餐切换到另外三项、同项单击、谨慎多项确认、失败重试、非法输入、币种保存、连续加减、忙碌防重复及并发快照保护。
- 新增11项Compose设备测试，覆盖实际点击金额切换、谨慎右上确认与区域外提示、2秒内松手、默认／加／减 × 快捷／谨慎六种组合的长按逐位删除及松手停止。
- v1.5 → v1.6正式包覆盖安装后，78条合成记录、52个合成账户身份及本机偏好逐项核对一致；沿用原证书，v2/v3签名通过。数据库结构未变，消费备份兼容旧格式。本机偏好不包含在消费备份中。
- 正式包检查了快捷切换后重启仍保留金额、谨慎按钮直接保存、长按连删及松手停止。中英日与横屏界面已检查；普通与红色减模式的键盘顶部及两侧无阴影黑边，横屏确认按钮与全部键位可见。

验证设备为专用MuMu Android12/API32模拟器，实体手机尚未验证。历史依赖旧界面或专用数据集的旧阶段测试不计入本次设备回归。原始日志及私有设备快照留在维护者本地，不进入公开仓库。
