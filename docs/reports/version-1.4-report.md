# v1.4 日期管理更新与验证

日期：2026-10-27（Asia/Shanghai）。版本1.4，versionCode=6。

## 实现

1. 原“删除”入口统一进入日期多选界面，按月份列出当前账户过去已有记录。支持跨月保留选择、全选/取消本月，确认页列出全部所选日期与数量后一次删除。选择一条也使用相同流程，不再提供独立单条删除入口。
2. 今天和未来日期不列入删除候选。批量删除许可绑定账户会话、日期及记录ID，执行前核对全部身份，数据库事务保证整批成功或整批回滚；不匹配的旧选择不能删除重建后的同日期记录。
3. 日历内空白过去日期可直接点按，创建早餐、午餐、晚餐、其他全零记录并进入该日，不弹生成确认。采用当前账户默认币种；唯一键与INSERT IGNORE保持幂等，已有金额、币种、记录类型和更新时间不会被重置。
4. 继续保护未确认金额草稿。存在实际修改时，先保存、放弃或继续编辑；这不属于创建记录的生成确认。日历与月度统计会在写入后刷新。
5. 保留三语言、时区、三餐设置、图表配色、离线行为和原数据库结构，无新增迁移。
