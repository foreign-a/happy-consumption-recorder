# v1.7 验收摘要

## 功能与边界

- 每项消费继续使用 `Long` 整数分存储，取消原 `9999.99` 上限。支持 `0`～`92233720368547758.07`，最多两位小数，拒绝负数、更多小数位和整数分溢出。
- 默认替换、加减、手动新增、记录修改及备份导入共用新的金额边界。加法检查 `Long` 溢出，减法不允许负结果；失败保留草稿。现有数据、币种和用户隔离规则不变。
- 日计、月计采用 `BigInteger` 精确累计，多项合法 `Long` 金额相加不会绕回负数；存储仍为 `Long`。饼图和柱图仅用浮点数计算绘制比例，金额显示仍取精确整数分。大金额统计行保留分类标签并允许金额换行。
- 所有默认／加／减 × 快捷／谨慎组合，按住删除键400毫秒后开始连删，每80毫秒一位，约每秒12.5位；松手、移出按键或取消立即停止。400毫秒前松手仅删一位，不产生延迟连删。
- 中文、英文、日文金额提示、键盘提示及无障碍删除说明已同步更新。Room结构与备份格式未修改，无需数据库迁移；旧备份仍兼容。本机偏好不包含在消费备份中。

- 55项Android设备测试通过，覆盖受控Compose时钟下400毫秒起删、每80毫秒精确删除一位、六种模式组合、短按、松手与取消停止、大金额保存与重建Activity、超界后修正、精确总额，以及数据与界面回归。
