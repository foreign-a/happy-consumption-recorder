# v1.3 更新与验收记录

日期：2026-10-21（Asia/Shanghai）。版本：1.3 / versionCode 4。

## 完成内容

1. 取消底部导航，右上角图标在用户 / 首页间切换，未确认输入仍需保存、放弃或继续编辑。
2. 首页默认展示用户时区的今日，消费记录改为平面金额布局。历史记录只能通过日期栏或月历选择后查看修改。数字键盘加大并常驻；保存后可继续输入。
3. 用户页新增本机按账户保存的 IANA 时区、早餐、午餐、晚餐时间。校验有效时区与早餐 < 午餐 < 晚餐。应用启动和回前台时按时区计算日期；有未确认草稿时保留原草稿，否则建议当前时间最近且相差不超过3小时的餐次，其余时间建议“其他”。采用时区规则处理夏令时，自动建议不写入金额。
4. 用户页新增可切换月份的每日消费柱形图，默认选中今日并滚动到相应日期。点击日期显示四项消费与当天合计；缺失记录明确显示无记录。不同币种分别绘图和汇总，不做汇率转换。
5. 日期行的“⋯”菜单保留批量生成历史与删除当前记录，原有单条删除确认、账户、语言、币种、备份功能保留。
