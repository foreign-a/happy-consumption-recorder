# v1.3.1 统计模块优化与验证

日期：2026-10-21（Asia/Shanghai）。

## 实现

- 月度条柱顶部使用4dp圆角并由 Compose 平滑绘制，底部保持基线对齐。
- 选中日期的四项明细下方增加饼图及颜色图例，展示金额和一位小数的百分比。
- 每类颜色支持8种预设色、任意六位十六进制RGB色及恢复默认。仅确认保存后提交，设置按账户独立保存在本机，适用于全部日期并在重启后保留。
- 零合计不绘制误导性饼图；混合币种分别绘图、分别计算分母；原四项明细和当天合计继续显示。
- 新增说明覆盖中文、英文、日文。统计和配色均不修改消费金额。
